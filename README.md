# Trimurya Transcriber

Production-ready manual transcription platform with React/Vite, Tailwind CSS, Express, MongoDB/Mongoose, secure JWT cookies, and private Cloudflare R2 audio storage.

## Local Installation

```bash
npm run install:all
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
npm run seed
npm run dev:backend
npm run dev:frontend
```

Open `http://localhost:5173`.

Sample users created by the seed script:

```text
100001 / ChangeMe123!
200001 / ChangeMe123!
300001 / ChangeMe123!
```

## Backend Environment

Required variables are documented in [backend/.env.example](backend/.env.example).

Use a long random `JWT_SECRET`, your MongoDB Atlas connection string, and Cloudflare R2 S3-compatible credentials. The frontend only needs `VITE_API_URL`; R2 credentials never belong in frontend environment variables.

## Cloudflare R2 Setup

1. Create a private R2 bucket.
2. Create R2 API tokens with object read/write access for the bucket.
3. Set `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET_NAME`, and `R2_ENDPOINT`.
4. Add this CORS policy to the bucket, replacing origins as needed:

```json
[
  {
    "AllowedOrigins": ["http://localhost:5173", "https://your-vercel-domain.vercel.app"],
    "AllowedMethods": ["GET", "PUT", "POST", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

Uploads use short-lived signed PUT/multipart URLs. Playback uses short-lived signed GET URLs generated by the backend after role checks.

## Vercel Frontend Deployment

1. Import the repository in Vercel.
2. Set root directory to `frontend`.
3. Build command: `npm run build`.
4. Output directory: `dist`.
5. Add `VITE_API_URL=https://your-render-api.onrender.com/api`.

## Render Backend Deployment

1. Create a Render Web Service with root directory `backend`.
2. Build command: `npm install`.
3. Start command: `npm start`.
4. Add all variables from `backend/.env.example`.
5. Set `CLIENT_URL` to the deployed Vercel URL.
6. Use MongoDB Atlas for `MONGODB_URI`.

## Implemented Workflows

- Admin project, team, upload, assignment, file management, review, report, activity, export, archive, and delete workflows.
- Transcriber assigned work dashboard and manual transcription workspace.
- Optional reviewer role with queue, audio workspace access, segment comments, approval, return, and rejection.
- Private R2 object storage with signed upload and playback URLs.
- MongoDB models for `User`, `Project`, `AudioJob`, `TranscriptionSegment`, `TagDefinition`, `Review`, `ActivityLog`, and `Notification`.
- CSV, JSON, TXT, SRT, and VTT exports.
- Locking when a user opens an audio job, autosave, submit for review, and revision history.

## Notes

Automatic AI transcription is intentionally absent. The architecture can support it later as a disabled backend option, but this app is manual-first.
